# SafeHer — Icons Directory

This folder will contain custom icon assets used in the SafeHer interface.

## Planned Icons

- `icon-sos.svg` — SOS emergency icon
- `icon-location.svg` — Location pin icon  
- `icon-contacts.svg` — People / contacts icon
- `icon-phone.svg` — Phone / helpline icon
- `icon-report.svg` — Document / report icon
- `icon-voice.svg` — Microphone / voice icon
- `favicon.ico` — Browser tab favicon
- `pwa-icon-192.png` — PWA icon (192×192)
- `pwa-icon-512.png` — PWA icon (512×512)

## Icon Guidelines

- Use SVG format for scalability
- Ensure icons have `aria-hidden="true"` when decorative
- Provide text labels alongside all icons
- Maintain consistent visual weight across icon set

Icons will be added in Step 2. Currently using Unicode emoji as placeholders.
