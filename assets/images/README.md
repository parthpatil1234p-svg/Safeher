# SafeHer — Images Directory

This folder will contain project images used throughout the SafeHer interface.

## Planned Images

- `logo.svg` — SafeHer SVG logo
- `hero-bg.jpg` — Landing page hero background
- `avatar-placeholder.png` — Default profile avatar
- `og-image.jpg` — Open Graph social preview image (1200×630)

## Image Guidelines

- All images must be compressed for web
- Use WebP format where browser support allows
- Provide appropriate `alt` text in HTML for all meaningful images
- Decorative images use `alt=""` and `role="presentation"`
