About This Project

SafeHer is an academic mini project designed to demonstrate a women's safety and emergency assistance system. It is built using HTML5, CSS3 and Vanilla JavaScript as the frontend prototype.

🛠️

Development Stage

Currently in Step 1: Frontend Prototype. Future steps will add Flask backend, SQLite database, authentication and real emergency workflow integrations.

📚

Technologies Used

Frontend prototype built with:

  • HTML5 (Semantic)
  • CSS3 (Custom Properties)
  • Vanilla JavaScript (ES6+)
⚠️ Disclaimer: SafeHer is an academic prototype. It is not a production emergency service. For real emergencies, contact official services: 112.
